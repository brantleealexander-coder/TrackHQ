# Example: Crossmar Tenant Config

Reference example showing what a real tenant's configuration looks like, drawn from the original Crossmar deployment.

This is **example data only** — the live Crossmar deployment continues to run from `Dispatcher_Andy/` until a separate migration project moves it onto TrackHQ.

Planned files here:
- `tenant_config.json` — the `TENANT_CONFIG_JSON` env value Crossmar would use under TrackHQ
- `business_config.json` — the receptionist business config
- `categories.csv`, `statuses.csv`, `locations.csv` — seed data for the tenant Supabase project
